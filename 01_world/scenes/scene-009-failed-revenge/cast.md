# Cast

## Summoned object agents

- namju
- sumin
- fake-artist
- guilt
- poverty

## Why each is here

- namju: 죽이고 싶지만 끝내 행동으로 완결하지 못하는 무력감을 대표한다.
- sumin: 복수조차 자신들의 삶을 되돌리지 못함을 먼저 몸으로 느낀다.
- fake-artist: 직접 등장하지 않아도 문 하나, 빛 하나로 두 사람을 압도하는 존재다.
- guilt: 칼을 쥔 손을 더 무겁게 만든다.
- poverty: 복수에도 준비와 미래가 필요하다는 현실을 잔인하게 드러낸다.
