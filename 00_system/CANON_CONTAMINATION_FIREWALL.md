# Canon Contamination Firewall

Use this document to stop drafts, brainstorms, and abandoned ideas from quietly becoming canon.

## Claim classes

- `draft claim`: appears in brainstorming or working notes only
- `candidate canon`: plausible, but not yet adopted into live truth
- `locked canon`: already propagated into world truth or frozen by checkpoint

## Promotion rule

No claim becomes canon only because it was mentioned once.

A claim is promoted only when:

1. it is intentionally adopted
2. it is written into the correct layer
3. its scope is clear
4. its provenance is known

## Never do this

- treat chat speculation as canon
- treat a discarded outline as canon
- treat a possible reveal as already true
- treat a scene draft as checkpoint truth before the system says so

## Safe promotion path

- idea enters `02_sources/` or working architecture
- if still useful, it becomes `candidate canon`
- if accepted, it is written into objects, scenes, arcs, threads, timeline, or canon
- the promotion is recorded in `01_world/canon/canon-ratification-ledger.md` when it becomes binding
- if later frozen, it enters a checkpoint

## Recovery rule

If contamination is detected:

- identify the false claim
- identify every board it touched
- demote or remove it
- record the event in `continuity-watchlist.md`
