# Start Readiness Gate

Use this document before any real story drafting begins.

Its job is to answer one question:

`Are we actually ready to write, or are we still only designing?`

## Gate outcomes

- `APPROVED`: drafting may begin
- `HOLD`: promising, but at least one blocking gap remains
- `REJECTED`: structure is still too incomplete or too unstable

## Manuscript creation rule

No first real manuscript file should be created in `03_manuscript/` until this gate is `APPROVED`.

## Minimum gate for any story

- the world seed is written
- the story mode is chosen: shortform | long-form | ultra-long-form
- the core promise is written
- the main POV or POV set is defined
- the central pressure or conflict is named
- the first irreversible movement is identified
- the author knows what the reader should want by the end of the opening

## Additional gate for long-form

- at least one active arc is defined
- at least one active thread is defined
- timeline anchor exists
- opening chapter purpose is explicit
- chapter-end traction rule is prepared

## Additional gate for ultra-long-form

- series start protocol is complete
- volume-001 has a central question
- the volume ending can both satisfy and force continuation
- at least one controlled misreading is defined
- at least one long-delay payoff is defined
- checkpoint policy is explicit
- canon contamination firewall is understood

If the project centrally involves coercion, trauma, or contested legal harm:

- core affected character state files are created before chapter 1
- unknown high-stakes fields are marked `unknown` rather than guessed
- research gaps are logged in `02_sources/`
- portrayal guardrails are named before approval

## Approval questions

1. What does the reader believe they are starting?
2. What does the protagonist want in the opening?
3. What is already broken before the first scene?
4. What must never be silently retconned later?
5. What makes this story worth more than one chapter?
6. If drafting started tomorrow, what would chapter 1 actually do?
