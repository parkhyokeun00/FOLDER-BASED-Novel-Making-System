# Chapter Build Checklist

Use this checklist before and after building a new chapter in a long or ultra-long project.

## Before writing

- Read the relevant `chapter-map.md` entry.
- Read the related object folders.
- Read the active arc entries.
- Read the active plot-thread entries.
- Read the latest relevant timeline entries.
- Read the latest checkpoint if the story is already large.

## After writing

- Save or revise the scene folders.
- Update affected object states.
- Update affected arc boards.
- Update the plot-thread ledger.
- Update the master timeline.
- Update chapter status in `chapter-map.md`.
- Add any continuity risk to `continuity-watchlist.md`.
- Create a checkpoint if a major boundary was crossed.
