# System Smoke Audit

Run this in five minutes right before a real story starts.

This is lighter than the simulation test.

## Check

- the chosen story mode matches the active boards
- no required start document is missing
- no authority conflict is already visible
- cadence is understood for the selected scale
- only the necessary layers are active
- unresolved contract gaps, if any, are explicitly named

## Pass

Pass if all six are true.

If not, patch the gap before drafting begins.
