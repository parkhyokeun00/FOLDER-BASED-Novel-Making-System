# Shortform Start Protocol

Use this for short stories and novellas.

The system for shortform must compress before it expands.

If the material wants 5 to 8 chapters, a verification phase, or a residue chapter after the reveal, read `MIDFORM_CASE_EXPANSION_GUIDE.md` before forcing pure shortform compression.

## Opening rule

Before scene 1 exists, complete:

- `world-seed.md`
- `opening-promise.md`
- `ending-lock.md`
- a first-scene preflight (scene-zero preflight)

## First three scene rule

- scene 1: expose the lack, pressure, or crack
- scene 2: sharpen relationship and external pressure
- scene 3: create an irreversible tilt

If this pattern is missing, the shortform opening is probably too loose.

## Compression rule

For every opening scene, ask:

- what is the one irreversible emotional change here
- what is the one image, line, or gesture this scene must earn
- if this scene vanished, what would the story lose

If the answer is weak, compress harder.

## First-scene preflight

Before writing the first scene, define:

- what the POV wants right now
- what the POV is hiding
- what the scene must leave behind emotionally
- what the last line must do
- what the reader should misread at first

If the POV is mainly an observer, witness, or investigator, also run `NARRATOR_MOTIVE_EARLY_CHECK.md`.

## Early payoff rule

Shortform cannot defer reward too long.

- strong emotional or structural payoff by 30 to 40 percent
- if novella, first clear payoff by 25 percent

## Subtext trigger

For the main relationship, define:

- what is said
- what is meant
- what the reader should not fully see yet
