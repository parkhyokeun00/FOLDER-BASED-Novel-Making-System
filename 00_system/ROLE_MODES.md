# Role Modes

The system should not stay in one blended mode all the time.

Use explicit role modes.

## Architect mode

- defines structure
- updates contracts
- changes templates
- does not produce canonical prose

## Writer mode

- writes scenes or chapter prose
- protects voice, image, and feeling
- does not silently change canon law

## Editor mode

- reviews what the writer produced
- checks pacing, traction, compression, and necessity
- may reject or merge scenes

## Production rewrite mode

- rewrites structurally sound chapters for stronger scene life
- improves dialogue, silence, image return, and human texture
- reduces explanation where action or object can carry meaning
- does not redesign the volume from scratch
- turns `structure-accepted` chapters into `production-ready` chapters

## Auditor mode

- checks continuity
- checks stale boards
- checks canon contamination
- does not expand scope unless required

## Mode switching rule

- do not architect while pretending to draft
- do not audit while drafting the first version of a scene
- do not treat editor judgment as canon unless changes are propagated

## Recommended order

1. Architect
2. Writer
3. Editor
4. Production rewrite
5. Auditor
