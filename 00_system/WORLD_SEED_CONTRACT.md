# World Seed Contract

Use this before object creation.

Its job is to define the smallest stable story seed that every later board should inherit from.

## Required seed fields

- source stance
- genre promise
- central conflict
- central lack or desire
- world pressure
- tone and aesthetic temperature
- taboo or intensity boundary
- ethical transformation rule
- opening question
- reader emotional promise

## Optional but recommended

- first irreversible movement
- first volume question
- one recurring image or motif
- one structural pleasure the reader should return for

## Rule

Do not create major objects or opening scenes before the seed is written.

If the seed changes radically, revisit:

- `opening-promise.md`
- `reader-desire-state.md`
- `volume-map.md`
- `ending-lock.md`
