# Production Rewrite Mode

Use this after the structure is stable and the chapter functions are already clear.

Its job is to improve novel quality without reopening the entire architecture.
This is the bridge between `structure-accepted` and `production-ready`.

## Default cadence

1. Review one chapter or one small tranche before editing.
2. If adjacent chapters or linked shorts are collapsing into the same house voice, run an explicit voice-separation pass before final gloss.
3. Ask reviewers for at most 3 to 4 pinpoint residual weaknesses for that same tranche. Favor line-level hits over broad impressions.
4. Land the rewrite for that same tranche before diagnosis gets too far ahead of visible prose movement.
5. If multiple workers touched prose, verify the landed file list before declaring the pass complete.

## Focus

- deepen lived scene presence
- sharpen dialogue and concealment
- add or refine private-life anchors
- protect attachment carryover so the reader does not emotionally restart every chapter or volume
- strengthen silence, pause, and emotional residue
- reduce explanation when image or action can carry the weight
- separate adjacent POV or episode rhythms when linked units start sounding like the same speaker
- cut repeat-proof passages where the reader already understands the meaning
- run a read-aloud breath pass and prefer micro-cuts when only explanatory tails remain
- tune recurring motifs so they return deliberately

## Questions for this pass

- What meaning has already landed and does not need to be re-proved?
- Which repetition is carrying pressure, ritual, or dread, and which repetition is only re-explaining?
- Where does the paragraph already clear in one breath?
- Where does the scene already stand before an explanatory tail arrives?
- What attachment line should deepen here rather than reset?
- Which adjacent chapters now share too much sentence rhythm, closure style, or emotional cadence?
- What is already strong enough to preserve rather than polish flat?

## Do not do in this mode

- invent new architecture to avoid rewriting
- waste review cycles on broad praise when residual weakness is what matters
- let review get so far ahead that visible prose movement disappears
- blanket-compress pressure-bearing repetition
- keep smoothing strong chapters until they collapse into the same house voice
- keep trimming once only micro-cuts remain and atmosphere would be the thing being cut
- silently change canon
- add pages only for bulk

## Pass condition

The chapter or tranche should feel more alive and pull harder forward, not merely shorter, longer, or prettier.

When this pass succeeds, the chapter may be marked `production-ready`.
