# New Story Bootstrap

Use this as the single entry point when starting a brand-new story from a structure-only workspace.

Its job is to remove startup hesitation.
It is a hard gate, not a suggestion.

## Raw motif intake rule

Before writing any prose, decide:

- is this original fiction, inspired fiction, adapted material, or transformed material
- what must be protected or not repeated literally
- what part of the source is structural fuel rather than sacred plot

Do this inside `WORLD_SEED_CONTRACT.md`, not inside the first draft.

## Influence translation rule

If the request strongly points to a living or protected authorial voice:

- do not copy the surface style
- run `LIVING_AUTHOR_STYLE_BYPASS_PROTOCOL.md`
- keep only a high-level style vector

## Choose the mode first

- `shortform`: short story or novella
- `midform`: 5 to 8 chapter case, novella-scale investigation, or middle-length suspense piece
- `long-form`: one novel or one volume-scale work
- `ultra-long-form`: multi-volume series

## First 60-minute build order

1. read `COMPLEXITY_BUDGET.md`
2. read `ROLE_MODES.md`
3. complete `WORLD_SEED_CONTRACT.md`
4. read `CANON_CONTAMINATION_FIREWALL.md`
5. if the project is a series, complete `SERIES_START_PROTOCOL.md`
6. complete `START_READINESS_GATE.md`
7. complete `VOLUME_001_LAUNCH_PROTOCOL.md` or `SHORTFORM_START_PROTOCOL.md`
8. create the first live launch boards
9. run `SYSTEM_SMOKE_AUDIT.md`
10. run `PREWRITE_SIMULATION_TEST.md`
11. if both pass, stop designing and begin writing

## Hard gate rule

Do not create the first real manuscript file in `03_manuscript/` before:

- `START_READINESS_GATE.md` is `APPROVED`
- `SYSTEM_SMOKE_AUDIT.md` passes
- `PREWRITE_SIMULATION_TEST.md` passes

Notes and temporary scratch files may exist elsewhere, but reader-facing drafting should not begin before this gate clears.

## First live launch boards

Create these before chapter 1 or scene 1:

- `01_world/architecture/world-seed.md`
- `01_world/architecture/opening-promise.md`
- `01_world/architecture/ending-lock.md`
- `01_world/reader/reader-desire-state.md`

For long-form and beyond:

- `01_world/architecture/volume-map.md`
- `01_world/architecture/chapter-map.md`
- `01_world/threads/plot-thread-ledger.md`
- `01_world/timeline/master-timeline.md`

For ultra-long-form:

- `01_world/architecture/storyline-weave.md`
- `01_world/architecture/volume-handoff-reentry.md`
- `01_world/canon/canon-ratification-ledger.md`

## Stop-designing line

Do not keep adding boards once all are true:

- the world seed is clear
- the opening promise is clear
- the ending lock is clear enough for the chosen scale
- the reader desire is named
- the first chapter or first scene can be described concretely
- smoke audit passes
- prewrite simulation passes

When those are true, structure work is done enough.
