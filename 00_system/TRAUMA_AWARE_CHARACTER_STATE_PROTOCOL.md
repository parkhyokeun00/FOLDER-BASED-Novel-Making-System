# Trauma-Aware Character State Protocol

Use this only when the story includes coercion, assault, intimidation, rumor-violence, institutional failure, contested testimony, or other trauma-bearing harm.

Its job is to preserve continuity and moral clarity by treating characters as evolving state variables, not fixed labels.

## Core rules

1. Character state changes after major events. Do not write high-harm scenes as if people reset between chapters.
2. If active harm is written in neutral, beautifying, or softening language, reader interpretation can be distorted.
3. When trauma materially affects the next chapter, character state must be updated before the next chapter begins.

## Use this protocol when

- power asymmetry is central to the scene
- consent, coercion, fear, or threat can be misread
- testimony conflict changes reader judgment
- legal or institutional framing changes the meaning of events
- compression might erase aftermath

## Character-state minimums for this mode

For core affected characters, `state.md` should track when relevant:

- physical condition
- fear baseline
- sleep or exhaustion state
- trust map
- shame or self-blame load
- agency level
- trigger map
- body markers
- truth-risk zone

Unknown fields may remain `unknown`, but must not be silently guessed.

## Pre-draft gate

Before drafting a chapter in this mode, confirm:

- which character states were reread
- what changed since the last chapter
- what remains uncertain
- which source, scene, or evidence supports high-stakes claims

Do not draft from memory when coercion, trauma, or contested testimony is carrying the chapter.

## Chapter-end rule

When a high-harm chapter materially changes a character's condition, log:

- chapter id
- event driver
- previous -> current state delta
- confidence
- evidence link
- open risk for next chapter

If there is no meaningful shift, write `no state shift` explicitly.

## Portrayal integrity gate

Before acceptance, remove wording that:

- frames forced compliance as free desire
- romanticizes or beautifies active harm
- hides power asymmetry that is factually central
- erases survival logic, fear logic, shock logic, or freeze logic

If the scene can be read as mutual when coercion is the factual core, the scene fails.

## Research trigger

Pause and research before drafting if:

- legal interpretation changes the meaning of force, coercion, threat, or consent
- rumor dynamics can invert victim and perpetrator framing
- contested testimony is central to the chapter
- trauma behavior is collapsing into stereotype

Store findings in `02_sources/`.

## Rule

If this protocol conflicts with speed, speed loses.
