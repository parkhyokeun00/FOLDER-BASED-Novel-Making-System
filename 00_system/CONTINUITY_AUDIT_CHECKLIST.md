# Continuity Audit Checklist

Use this after important chapters and at every act or volume close.

## Stale-board check

If the chapter changed one of the following, confirm the board is updated:

- object state
- object hooks
- character-state arc
- relationship arc
- world-conflict arc
- foreshadow-payoff arc
- plot-thread ledger
- master timeline
- emotional pulse
- reader memory
- misreading design
- traction log
- source reference notes when the chapter materially depended on outside material

Mark anything missing as `STALE` until updated or explicitly waived.

## Conflict check

- Does any object state contradict a later scene aftermath?
- Does any scene chronology contradict the master timeline?
- Does any arc summary contradict explicit scene fact?
- Does architecture still match the living story?
- Does manuscript wording drift from frozen checkpoint truth?

## Reader check

- Is a major payoff approaching without reminder?
- Is a controlled misunderstanding about to break without adequate hinting?
- Has the reader's desire state shifted without the system recording it?

## Voice check

- Has POV voice drifted?
- Has exposition flattened subtext?
- Has chapter pacing become monotonous in texture or closing force?
- Has reader-facing prose leaked internal chapter numbering or planning language?

## Audit outcome

For each issue:

- update immediately, or
- record the reason for delay in `continuity-watchlist.md`
