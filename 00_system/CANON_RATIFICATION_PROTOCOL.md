# Canon Ratification Protocol

The firewall prevents contamination.
This protocol records deliberate promotion.

## Use the ratification ledger when

- a world rule becomes binding
- a hidden truth is officially adopted
- a tone or taboo boundary becomes fixed
- a major relationship fact becomes canon
- a series-level promise becomes irreversible

## Each ratified claim should record

- claim id
- source
- approval status
- rationale
- affected files
- first binding checkpoint

## Rule

No high-impact claim should become canon without a traceable ratification record.
