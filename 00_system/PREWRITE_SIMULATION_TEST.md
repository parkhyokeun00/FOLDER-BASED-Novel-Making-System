# Prewrite Simulation Test

Run this before drafting a real story.

The goal is to test whether the system operates cleanly, not to produce a real scene.

## Simulation scope

Create one fake mini-case only:

- 2 temporary objects
- 1 temporary pressure or force
- 1 temporary scene
- 1 temporary thread
- 1 temporary timeline entry

Do not use a real novel idea yet.

## Test sequence

### Test 1. Object creation

- create temporary object folders
- confirm the object contract is clear
- confirm the POV can select them without ambiguity

### Test 2. Scene-close

- create one temporary scene folder
- write `brief.md`
- write `cast.md`
- write a minimal `draft.md`
- write `aftermath.md`
- confirm the aftermath is enough to drive updates

### Test 3. Chapter-close

- update one arc
- update one thread
- update one timeline entry
- update reader desire or memory if relevant
- update traction

### Test 4. Authority conflict

Simulate a contradiction:

- object says one thing
- scene says another

Confirm the team can resolve it through `AUTHORITY_MATRIX.md`.

### Test 5. Audit

- run `CONTINUITY_AUDIT_CHECKLIST.md`
- mark any missing or unclear board as `STALE`

## Pass condition

The simulation passes only if:

- no one needed memory alone
- aftermath was enough to drive updates
- the authority conflict had a clear answer
- the audit found no ambiguous contract

## Failure response

If the simulation fails:

- do not start drafting
- patch the missing contract first
