# Volume 001 Launch Protocol

Use this when starting the first real volume of a new story.

Volume 001 is not just the beginning.
It is the contract the whole work will be judged by.

If this is a series project, complete `SERIES_START_PROTOCOL.md` first.

## Step 1. Lock the opening promise

Complete `01_world/architecture/world-seed.md`.
Complete `01_world/architecture/opening-promise.md`.
Complete `01_world/architecture/ending-lock.md`.

You must define:

- genre promise
- emotional promise
- first-three-chapter effect
- core question
- one pleasure the reader should return for

## Step 2. Define the engine

Before chapter 1 exists, name:

- core engine: what can keep this story alive for more than one chapter
- irreversible promise: what you cannot betray later
- escalation ladder: what grows across the volume
- terminal image or terminal emotional state

## Step 3. Prepare Volume 001 as a sellable unit

Volume 001 must stand on its own.

Define:

- the volume question
- the opening state
- the ending state
- the expected chapter or movement range
- one answered promise
- one sharpened carry-over hunger

## Step 4. Build the opening run

For long-form, complete:

- `opening-10-blueprint.md`
- `early-payoff-schedule.md`
- `reader-desire-state.md`
- `LONGFORM_EXPANSION_PROTOCOL.md` if the draft keeps collapsing back into shortform scale

For shortform or novella, use `SHORTFORM_START_PROTOCOL.md` instead of the full opening-10 board.

## Step 5. Open the first threads

Before drafting begins, define:

- 3 to 5 opening promises or threads
- which one pays off early
- which one remains unresolved longer
- which one should be misunderstood at first

## Step 6. Protect what must stay flexible

Do not over-lock volume 001.

Before drafting, mark:

- what is locked now
- what is intentionally provisional
- what must not be canonized yet

## Step 7. Run the prewrite simulation

Run `PREWRITE_SIMULATION_TEST.md`.

If the simulation fails, return to design.

## Step 8. Pass the readiness gate

Complete `START_READINESS_GATE.md`.
Only after approval should actual drafting begin.

## Step 9. Protect long-form scale

If the project is long-form:

- define a chapter-003 scale check
- if the draft is collapsing into shortform compression by then, pause and run `LONGFORM_EXPANSION_PROTOCOL.md`
